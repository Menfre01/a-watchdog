# Proposal

## Why

轨迹页曾有一个四组折叠图例。页面简化后，多数条目已就地解释：轴口径在轴下方，斜纹与工具段有悬停提示，分类徽标自带 title。集中式图例要求读者先展开再对照，成本高于收益。

## What Changes

- 删除轨迹页的「图例 · 怎么看」折叠块。
- 改为就地说明：非直观符号在其出现处给出提示。
- 规范里删除集中式图例要求，新增就地说明要求。

## Capabilities

- 修改 `admin-console`：以「就地说明」替代「视图图例」。

## Impact

- 前端：删除图例组件与它引用的常量。
- 规范：一条要求替换为另一条。
