# Spec Delta

## REMOVED Requirements

### Requirement: 视图图例

**Reason**: 集中式图例与页面内的就地说明重复，读者需要先展开再对照。

**Migration**: 每个非直观符号改为在出现处说明。轴口径写在轴下方，斜纹与工具段用悬停提示，分类徽标用 title。

## ADDED Requirements

### Requirement: 就地说明

轨迹 **必须(MUST)** 在每个非直观符号的出现处给出说明。集中式图例不 **得** 作为唯一说明手段。

时间轴 **必须** 在轴下方写明口径，包括覆盖范围与 harness 段的算法。斜纹段、工具色块与 harness 数值 **必须** 带悬停提示。分类徽标 **必须** 用自身提示说明含义。

说明文字 **必须** 短于两句。说明 **不得** 重复页面其它位置已有的信息。

#### Scenario: 轴口径就地可见

- **WHEN** 读者看到时间轴
- **THEN** 轴下方可见覆盖范围与 harness 算法的说明

#### Scenario: 符号带提示

- **WHEN** 读者把鼠标停在斜纹段、工具色块或分类徽标上
- **THEN** 出现对应的含义说明

#### Scenario: 新增符号

- **WHEN** 页面新增一个非直观符号
- **THEN** 该符号在出现处带说明，不依赖集中式图例
