# Spec Delta

## ADDED Requirements

### Requirement: 工具入参与结果

上报 **可以** 携带工具入参与结果。服务端 **必须(MUST)** 保存两者,并按 `tool_call_id` 与对应调用关联。

单字段 **必须** 有 256 KB 上限。超过上限时 **必须** 只保留前缀并标记截断。

客户端未上报时,读取侧 **可以** 用轨迹复原值兜底。兜底值 **必须** 标明来源,不得与上报值混同。

#### Scenario: 上报入参与结果

- **WHEN** 客户端在开始与结束事件里分别携带入参与结果
- **THEN** 两个字段随事件落库,读取时可取回

#### Scenario: 超限截断

- **WHEN** 入参或结果超过 256 KB
- **THEN** 只保存前缀,并标记截断

#### Scenario: 未上报

- **WHEN** 客户端没有上报入参与结果
- **THEN** 读取侧退回复原值,并标明来源
