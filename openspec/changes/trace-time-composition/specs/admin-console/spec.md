# Spec Delta

## ADDED Requirements

### Requirement: 时间构成与工具段

轨迹统计卡 **必须(MUST)** 给出两段时间的合计:**模型** 与 **工具**,并给出工具占机器时间的比例。

- 模型段取各步 `latency_ms` 之和，是实测值。
- 工具段取已配对工具事件的区间并集，口径是事件边界，**必须** 标注含客户端处理。并行调用 **不得** 重复计时。工具 **必须** 归到生成该调用的步，不得归到它的下一步。工具段 **不得** 越过 harness 段。窗口超出时按 harness 截断显示。
- 两段 **必须** 用行内数字显示，不得单独占用时间轴色条。
- 输入时间与空闲时间 **不得** 进入构成。它们仍由客户端采集,供需要时查阅。
- 工具事件数少于轨迹中的工具调用数时, **必须** 给出一条数据完整性提示,说明工具耗时可能偏低。

两段 **必须** 各自给出数值与数量：模型按步数，工具按已配对调用数。

#### Scenario: 两段都有数据

- **WHEN** 会话含模型请求与工具调用
- **THEN** 统计卡只显示模型与工具两段合计与数量

#### Scenario: 没有工具调用

- **WHEN** 会话全程没有工具调用
- **THEN** 构成条省略工具段，统计卡不显示工具耗时

#### Scenario: 时间轴工具段

- **WHEN** 某步发起了工具调用且有配对的工具事件
- **THEN** 该步的时间轴在模型条之后出现工具段，悬停显示该段时长
