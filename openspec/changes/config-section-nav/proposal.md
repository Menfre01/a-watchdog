# Proposal

## Why

侧栏并列五个入口,其中接入、模型目录、客户端密钥同属配置类,却不是同一层。五项目录让「可观测」与「配置」两条主线看不出边界。配置内部再分页,又会把同类操作藏进标签页,管理员看不到全局。

## What Changes

- 侧栏改为两个模块:**可观测**、**配置**。
- 配置模块以孤岛铺开三个管理区:**接入**、**模型目录**、**客户端密钥**。三个孤岛同页可见,不做分页。
- 每个孤岛自带标题与主操作,只管理自己的数据。
- 各配置页不再自带一级标题;配置模块给出一级标题,孤岛用二级标题。
- 视觉上引入孤岛样式:面板有圆角、轻阴影与留白,与页面底色分层。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `admin-console`: 新增「控制台导航分组」要求,明确侧栏两个模块与配置模块的孤岛布局。

## Impact

- 前端:`web/src/App.vue`、`web/src/views/Providers.vue`、`Models.vue`、`Keys.vue` 的结构与样式。
- 令牌:新增孤岛圆角与阴影。
- 后端与存储:无改动。
