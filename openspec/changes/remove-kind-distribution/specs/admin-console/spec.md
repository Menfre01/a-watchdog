# Spec Delta

## REMOVED Requirements

### Requirement: 会话分类分布

**Reason**: 统计卡改为时间构成，会话级分布与时间口径并列会分散注意力。

**Migration**: 分类改由每步的徽标与图例呈现；读取逐步分类即可，不再提供会话级汇总。

### Requirement: 分类分布的口径说明

**Reason**: 说明服务于已删除的分布条。

**Migration**: 「无重合」与链数的区分写在图例对应条目里，读者可从图例与步徽标获得同一信息。

### Requirement: 首步等于链数的不变量

**Reason**: 该不变量用于核对分布条，分布条已移除。

**Migration**: 链数仍由会话头的链汇总给出；「首步」的语义保留在徽标文案中。
