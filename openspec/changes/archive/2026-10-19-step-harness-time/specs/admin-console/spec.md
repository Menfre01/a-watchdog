# Spec Delta

## ADDED Requirements

### Requirement: 各步的 harness 侧耗时

轨迹视图 **必须(MUST)** 为每条步给出 harness 侧耗时。它的口径 **必须** 写明:该值等于**同链**下一步请求的开始时间减去本步结束时间。

本步结束时间 = 本步开始时间 + 本步耗时(记录侧实测值)。

该值 **必须** 标明为推算。视图 **必须** 说明它含三部分:工具在客户端的执行、客户端自身的处理、轮次边界处人的思考。三者 **不得** 分开显示,视图也 **不得** 把该值称为「工具耗时」,那会让读者以为它只覆盖工具执行。

视图 **必须** 说明该窗口的范围。窗口含客户端在同期为**其它链**所做的工作。它也含同期对**其它端点**的请求,那些请求不生成 step。视图 **不得** 把该值当作该步独占的工作量。

本步耗时 **必须** 标明其口径:记录在**请求体读完**之后开始计时,故本步耗时不含读取请求体的时间。请求体的上传时间因此落在 harness 侧窗口内。

#### Scenario: 每步给出 harness 侧耗时

- **WHEN** 读者查看某一步
- **THEN** 该步给出 harness 侧耗时,并标明为推算

#### Scenario: 口径写明含三部分

- **WHEN** 读者查看该值的口径说明
- **THEN** 说明指出它含工具执行、客户端处理与人的思考时间,且三者不可拆分

#### Scenario: 口径写明窗口的范围

- **WHEN** 读者查看该值的口径说明
- **THEN** 说明指出窗口含同期为其它链所做的工作,也含不生成 step 的其它请求。说明还指出该值不是该步独占的工作量

#### Scenario: 本步耗时的口径写明

- **WHEN** 读者查看本步耗时的口径
- **THEN** 说明指出计时从请求体读完开始,故不含请求体的读取时间

### Requirement: harness 侧耗时在时间轴上的标记

时间轴 **必须(MUST)** 用与实测条不同的样式标出 harness 侧时间段。该段从本步条的右端画到**同链**下一步条的左端。该段 **不得** 使用实测条的实心样式。

该段 **不得** 跨链画:一段 harness 侧耗时 **必须** 只在同链相邻两步之间给出。旁路请求的到达时间 **不得** 算进主路步的 harness 侧耗时。

后继落在下一轮时,超出本轮轴范围的段 **必须** 裁掉,并 **必须** 在提示里说明该值延续到下一轮。数值本身 **必须** 给全量。

#### Scenario: 时间轴以独立样式标出该段

- **WHEN** 读者展开一个有多步的轮次
- **THEN** 每步之后可见一段与实测条样式不同的标记,长度对应该步的 harness 侧耗时

#### Scenario: 不跨链画段

- **WHEN** 本步之后先到达的是另一条链的请求
- **THEN** 该步的 harness 侧耗时只按同链下一步计算,不按那条旁路请求的到达时间计算

#### Scenario: 后继在下一轮时裁掉超出部分

- **WHEN** 同链下一步落在下一轮
- **THEN** 本轮轴上的段止于轴末端,提示说明该值延续到下一轮,数值仍给全量

### Requirement: harness 侧耗时的边界情形

一条链的最后一步没有后继请求。此时该值 **必须(MUST)** 显示为「—」,且 **不得** 画段。

推算结果为负时(并行请求导致后继请求早于本步结束),该值 **必须** 显示为「—」,且 **不得** 画段。该情形 **不得** 显示为 0:它是「不可测」,不是「没花时间」。

#### Scenario: 链末步显示「—」

- **WHEN** 某步是该链的最后一步
- **THEN** 该步的 harness 侧耗时显示为「—」,轴上不画段

#### Scenario: 负值显示「—」而不是 0

- **WHEN** 同链下一步的开始时间早于本步结束时间
- **THEN** 该步的 harness 侧耗时显示为「—」,轴上不画段,且不显示为 0
