# Proposal

## Why

工具入参与结果现在靠下一轮请求复原。最后一步没有下一次请求，客户端改写历史时也会失真。钩子本就携带这两个字段。

## What Changes

- `tool_events` 增加入参与结果的 gzip 列，单字段上限 256 KB。
- 开始事件写入入参，结束事件写入结果。超限标截断。
- 读取接口返回上报值。轨迹优先用上报值，缺失时退回复原值。
- 状态文案改为完成、失败、未知。

## Capabilities

- 修改 `tool-timing`：新增入参与结果的采集与状态口径。
- 修改 `admin-console`：工具条目优先使用上报值。
