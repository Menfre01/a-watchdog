# Spec Delta

## MODIFIED Requirements

### Requirement: 会话链汇总

轨迹视图 **必须(MUST)** 在会话层给出链汇总:主链条数与旁路链条数。主链 **必须** 按链归属的判据选定:至少两个非重复步的链中时间最早的一条,没有这样的链时取含会话首步者。主链恒为 1 条。

旁路 **必须** 另外给出步数与 token 用量(in / out),与会话总量并列。占比 **可以** 由界面按已给数值算出,无需新字段。

链汇总 **必须** 标明为推断。视图 **必须** 写清判据:同一条链的判据是 system 指纹与首条 user 指纹两级相同。两侧都相同才归入同一条链。

#### Scenario: 会话头给出链汇总

- **WHEN** 读者打开一个含旁路链的会话
- **THEN** 会话头给出主链条数与旁路链条数,并给出旁路的步数与 token 用量

#### Scenario: 链数标明为推断并带判据

- **WHEN** 读者查看链汇总
- **THEN** 该数值标明为推断,并可读到判据(system 指纹与首条 user 指纹两级相同)

#### Scenario: 一次性自动请求先到时主链仍正确

- **WHEN** 会话的第一步是生成标题请求,主对话在其后反复出现
- **THEN** 主对话所在链计入主链
- **THEN** 生成标题与安全监控都计入旁路链
