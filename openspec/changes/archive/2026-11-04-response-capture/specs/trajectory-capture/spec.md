# Spec Delta

## ADDED Requirements

### Requirement: 上游响应原文

系统 **必须(MUST)** 按请求保存上游响应原文。保存 **必须** 异步进行，不得阻塞或改写转发给客户端的内容。

单条响应 **必须** 有大小上限。超过上限时 **必须** 只保留前缀，并标记截断。客户端中断导致响应不完整时， **必须** 标记不完整。

读取侧 **必须** 给出响应内容：文本、思考、工具请求、停止原因与用量。没有记录的请求 **必须** 说明未记录，不得复原成看似完整的内容。

#### Scenario: 记录响应

- **WHEN** 客户端发起一次正常推理请求
- **THEN** 系统保存该请求的响应原文，并标记为完整

#### Scenario: 超限截断

- **WHEN** 响应原文超过大小上限
- **THEN** 系统保存前缀，并标记截断

#### Scenario: 客户端中断

- **WHEN** 客户端在响应完成前断开
- **THEN** 系统保存已收到的部分，并标记不完整

#### Scenario: 旧数据无响应

- **WHEN** 查看早于本变更的请求
- **THEN** 界面说明该步响应未记录
