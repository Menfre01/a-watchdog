# 手工验收清单

以下五项需要浏览器逐条检查。每项给出操作、预期与失败判定。

## 1. 折叠状态持久化

操作:

1. 在侧栏底部点折叠按钮，确认侧栏变成图标态。
2. 刷新页面。
3. 打开开发者工具控制台，执行 `localStorage.getItem('awatchdog.sidebar')`。

预期:

- 刷新后仍为图标态。
- 存储值为 `collapsed`。
- 再点一次恢复展开，存储值变为 `expanded`。

失败判定：刷新后自动展开，或存储值不是上述两者。

## 2. 主题持久化与首屏不闪

操作:

1. 点主题切换按钮，记下当前主题。
2. 在开发者工具把网络限速设为 Slow 3G,CPU 降速 6 倍。
3. 硬刷新(`Cmd+Shift+R`),观察第一帧。
4. 执行 `localStorage.getItem('awatchdog.theme')`。

预期:

- 刷新后主题与切换后一致，存储值为 `dark` 或 `light`。
- 第一帧背景与最终背景一致，看不到亮色闪帧。
- 清空该键后刷新，主题取系统偏好。

失败判定：首帧出现白色或亮色闪动。刷新后主题回退。存储值缺失但界面已切换。

## 3. 375px 无整页横滚

操作:

1. 开发者工具切到设备模式，宽 375、高 812。
2. 打开「可观测」，进入任一轨迹，展开两个 step。
3. 控制台执行 `document.documentElement.scrollWidth` 与 `document.documentElement.clientWidth`。

预期:

- 两个数值相等，页面没有整页横向滚动条。
- 宽表格在自身容器内滚动，不撑开页面。
- 侧栏为图标态，不遮挡内容。

失败判定:`scrollWidth` 大于 `clientWidth`。或内容被裁切，无法滚动查看。

## 4. 弹窗 Esc 与回焦

操作:

1. 打开「客户端密钥」，按「新建密钥」。
2. 不点鼠标，直接按 `Esc`。
3. 再打开一次，点「取消」。
4. 每次关闭后观察焦点位置。

预期:

- `Esc` 关闭弹窗。
- 关闭后焦点回到触发按钮「新建密钥」。
- 弹窗打开期间背景不可滚动，关闭后恢复。
- 再次打开时焦点落在第一个输入框。

失败判定:`Esc` 无效。焦点落回页面顶部或消失。背景仍可滚动。

## 5. 键盘可展开轨迹

操作:

1. 只用键盘，从页面顶部按 `Tab` 移到轮次行。
2. 按 `Enter` 展开，再按 `Enter` 收起。
3. 继续 `Tab` 到 step 行，重复。
4. 检查焦点环是否可见。

预期:

- 轮次行与 step 行可获得焦点，焦点环清晰。
- `Enter` 与 `Space` 都能切换展开。
- 展开状态与 `aria-expanded` 一致。

失败判定：无法聚焦。按键无反应。焦点环不可见或与背景同色。
