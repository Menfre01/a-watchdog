# Spec Delta

## MODIFIED Requirements

### Requirement: 请求指标岛

可观测页 **必须(MUST)** 在请求指标岛之前提供筛选条。筛选条 **必须** 支持时间范围、client key 与 session 标识前缀。三个条件 **必须** 可叠加。筛选条 **不得** 要求额外的查询按钮。

可观测页 **必须** 提供「请求指标」岛，显示所选时间范围与筛选范围内的五项数据:

- 请求数
- 错误数与错误率
- 延迟 p50 与 p95
- 缓存命中率
- 输入与输出 token 合计

时间范围 **必须** 可选 1 小时、24 小时、7 天、全部，默认 24 小时。时间范围 **必须** 由筛选条提供。指标岛 **不得** 再提供独立的窗口按钮。

筛选条 **必须** 同时作用于请求指标与会话列表。时间或 key 变化后，两者 **必须** 立即使用同一组条件刷新。session 前缀变化后，两者 **必须** 在短延迟后刷新。按 Enter **必须** 立即刷新。会话列表的默认范围 **必须** 从全部改为最近 24 小时。

按 client key 筛选时，指标 **必须** 统计该 key 的全部请求，包含没有快照的请求。按 session 标识前缀筛选时，指标 **必须** 只统计有快照且前缀匹配的请求。没有快照的请求 **不得** 计入。界面 **必须** 说明这一限制。

会话列表只覆盖有快照的会话。指标在 key 筛选时覆盖该 key 的全部请求。两者不要求行数完全相等。

错误率 **必须** 按「状态码 4xx 以上或带错误类型的请求数 ÷ 请求总数」计算。缓存命中率 **必须** 按「缓存读取 ÷(输入 + 缓存读取)」计算，分母为 0 时显示 0。

分位数 **必须** 取升序延迟的第 `ceil(p × n)` 个样本。窗口内筛选后的样本少于 20 个时，界面 **必须** 说明分位数参考意义有限。

#### Scenario: 显示窗口指标

- **WHEN** 管理员打开可观测页
- **THEN** 看到默认最近 24 小时、未设置 key 与 session 时的请求数、错误率、p50、p95、缓存命中率与 token

#### Scenario: 切换窗口

- **WHEN** 管理员在筛选条选择 7 天
- **THEN** 指标与会话列表立即按最近 7 天重新计算，key 与 session 条件保持不变

#### Scenario: 默认范围同时作用于列表

- **WHEN** 管理员打开可观测页
- **THEN** 会话列表默认只显示最近 24 小时的会话
- **AND** 选择「全部」后可见更早的会话

#### Scenario: 样本不足

- **WHEN** 窗口内筛选后的请求少于 20 个
- **THEN** 界面说明分位数参考意义有限

#### Scenario: 按密钥筛选指标

- **WHEN** 管理员选择某个 client key
- **THEN** 指标立即只统计该 key 的请求，包含没有快照的请求

#### Scenario: 按 session 前缀筛选指标

- **WHEN** 管理员输入 session 标识前缀
- **THEN** 短延迟后指标只统计有快照且标识前缀匹配的请求

#### Scenario: 按 Enter 立即筛选

- **WHEN** 管理员在 session 前缀输入框按 Enter
- **THEN** 指标与会话列表立即刷新，不等待防抖计时结束

#### Scenario: 三个条件叠加

- **WHEN** 管理员选择时间范围、client key 并输入 session 标识前缀
- **THEN** 指标只统计该时间范围内、该 key 下、标识前缀匹配且有快照的请求

#### Scenario: 无快照请求不计入 session 指标

- **WHEN** 管理员按 session 标识前缀筛选
- **AND** 某个请求没有快照
- **THEN** 该请求不计入指标
- **AND** 界面说明这一限制

#### Scenario: 指标与会话列表同步

- **WHEN** 管理员修改时间、key 或 session 条件
- **THEN** 会话列表与请求指标使用同一组条件刷新
