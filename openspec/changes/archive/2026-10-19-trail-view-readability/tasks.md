## 1. 后端:骨架新增字段

- [x] 1.1 时间轴偏移:骨架每步新增 `at_ms`(相对本轮轴起点的偏移)。轮次新增 `duration_ms`。条长用已有的 `latency_ms`,不另存等值字段。轴跨度取本轮全部请求,含旁路步。验证:表驱动测试覆盖 5 种情形(单步轮 / 多步轮 / 含旁路步 / 起点不在第一步 / 时间戳不可解析)
- [x] 1.2 分类分布:骨架新增 `kinds`,给出 6 个分类各多少步。细分标记(摘要压缩 / 上下文清零 / 末行更新)单独计数。验证:测试断言分类分项之和等于步数,且细分不计入分项之和
- [x] 1.3 故事线段:骨架每轮新增 `story`,段序列为「首步分类 → 行数合计 → 首个细分标记 → 失败计数」。每段带可选 `seq` 供跳转。验证:表驱动测试覆盖 5 种情形(首步轮 / 追加加失败 / 压缩轮 / 旁路步不进叙述 / 无行数变化)
- [x] 1.4 失败判据复用:失败清单不新增字段,由前端从 steps 的 `status_code` 与 `error_kind` 派生。验证:测试断言骨架不输出失败列表字段,且失败步的派生输入(状态码)在骨架里
