# Proposal

## Why

会话头现在只有轮次、步数与混合的 token 汇总。读者回答不了「这个会话开了几条独立对话」。旁路链的规模与代价只能逐轮点开 tab 才看得到,而旁路请求正是请求数与 token 膨胀的常见来源。

## What Changes

- 会话层新增**链汇总**:主链条数与旁路链条数。主链 **必须** 定义为含会话首步的那条链,恒为 1 条。
- 新增**旁路占比**:旁路步数与旁路 token(in / out),与会话总量并列。读者据此分清多出来的请求是客户端自动请求还是并行分扇。
- 链汇总与占比 **必须** 标明为推断,判据 **必须** 写明:同一条链的判据是 system 指纹与首条 user 指纹两级相同。
- 链归属不可判定时 **必须** 如实显示。任一步缺 system 指纹时,归属退化为不拆分。此时 **不得** 把「1 条链」当成事实显示,应显示「—」并说明原因。
- 链汇总 **只进轨迹视图**,不进会话列表。链归属要对每个会话做整段指纹比对,成本随会话数线性放大,与列表不含轮次数是同一取舍。
- 轮级已有的「旁路 N 步 / M 条链」**必须** 写明口径为「本轮出现的链」,与会话层的「共 N 条链」区分。

**BREAKING**: 无。骨架接口只增字段,不改已有字段。

## Capabilities

### New Capabilities

无。本变更只扩展现有控制台视图。

### Modified Capabilities

- `admin-console`: 轨迹视图的会话头新增链汇总与旁路占比,并写明其判据与退化口径。

## Impact

- 代码:`pkg/admin/trace_json.go`、`pkg/admin/traces.go`、`web/src/views/TracePanel.vue`、`web/src/api.ts`、`docs/trail-view.html`。
- 接口:`GET /console/api/traces/{session_id}` 会话层新增字段。只增不改,旧前端仍可用。
- 依赖:无新增。链归属已由 `pkg/trace` 给出,本变更只做汇总与显示。
