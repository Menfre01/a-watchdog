# Spec Delta

## ADDED Requirements

### Requirement: 分类分布的口径说明

分类分布条 **必须(MUST)** 说明「无重合」这一分类的含义:它统计链内内容断层的步,不是链数。说明 **必须** 同时指出链数在何处给出,即会话头的链汇总。

该说明 **必须** 与图例中对应条目同源,不得到处各写一份。

#### Scenario: 无重合给出区分口径

- **WHEN** 读者查看分类分布条中的「无重合」
- **THEN** 可见说明指出它统计链内的内容替换步,不是链数,并指出链数见会话头的链汇总

#### Scenario: 图例与分布条同源

- **WHEN** 读者比较分布条与图例里关于「无重合」的说法
- **THEN** 两处文案来自同一来源,含义一致

### Requirement: 首步等于链数的不变量

分类分布条 **必须(MUST)** 给出这条不变量:分类为「首步」的步数等于链总数,即主链 1 条加旁路链 N 条。读者据此与会话头的链汇总互相印证。

链首快照为空时该步会记成「无重合」,不变量不成立。文案 **必须** 把这一退化情形排除在外,**不得** 无条件声称两者恒等。

#### Scenario: 分布条给出不变量

- **WHEN** 读者查看分类分布条
- **THEN** 可见说明指出「首步」段等于链总数,并写明链首快照为空的退化情形不在其内

#### Scenario: 与会话头互相印证

- **WHEN** 会话里存在旁路链
- **THEN** 分布条的「首步」段与会话头链汇总给出的链总数一致

#### Scenario: 不变量有测试锁定

- **WHEN** 运行后端测试
- **THEN** 有测试断言非空快照下「首步」步数等于链总数,断言失败表示分类或归属有问题
